# PTseq 提取产物定量与均一化验证报告

## 范围

- 分支：`feature/extraction-normalization`
- 提取脚本：保持 45 uL 回收，新增提取产物交接清单。
- 建库脚本：library-only、G99 full、E25 full、2000/200 full。
- sequencing-prep-only 从已完成建库的产物开始，不重复执行提取均一化，因此未改。
- 配套更新：4 套建库 deck、中台数据库/迁移脚本/台面图、试剂分装表。

## 液体契约

1. POS8 Col1-6 提取产物每孔 45 uL。
2. 每个样本取 2.2 uL 到 POS14 Col7-12 定量管，与 217.8 uL Qubit 染液构成 220 uL 体系。
3. 均一化目标为 20 ng/uL、30 uL，产物位于 POS8 Col7-12。
4. `0 < C < 20`：不补水，转移 30 uL，保留实测浓度。
5. `20 <= C <= 200`：样本体积 `600/C` uL，补水 `30 - 600/C` uL。
6. `C <= 0` 或 `C > 200`：生成计划表后、移液前停止，避免无效浓度或小于 3 uL 的样本取液。
7. 每个样本用独立 50 uL 枪头转移并以 25 uL 混匀 5 次。补水使用一支水专用 50 uL 枪头，仅接触水和空目标孔。
8. 建库从均一化孔取 14 uL；目标孔理论剩余 16 uL。原始提取孔最低理论剩余 12.8 uL。

## 板位与中转

- POS8 Col1-6：提取产物原液；Col7-12：均一化目标孔。
- POS14 Col7-12：提取产物定量；Col1-6：建库产物定量。
- POS24 A2：无核酸水；POS24 B1 保持原 T2 位置。
- POS30：固定第 5 盒 50 uL 枪头，不再做机械臂中转位。
- POS13 中转前：纯化深孔板 POS16 -> POS23，POS13 染液深孔板 -> POS16；中转完成后按反向顺序恢复。
- PCR 板 POS20/POS9 交换只通过 POS13，PCR 板不进入 POS16。
- 三个 full 流程均使用 POS11 Col7 pooling：POS11 深孔板先移到 POS23，临时空出的 POS11 用于纯化板停放。POS14 始终保留定量管适配器。

| Library-only | 387 | 480 | 93 |
| G99 full（1 DNB） | 440 | 480 | 40 |
| E25 full（2 DNB） | 439 | 480 | 41 |
| 2000/200 full | <=438 | 480 | >=42 |

2000/200 在“48 个样本全部触发后续高浓度稀释”的保守情形下，300 uL 枪头估算上限约 357/384，余量约 27。这是静态上限核算，需在水跑中验证备用枪头盒交换。
